Your key

Answers are simulated on this device until you add a key. With one, requests go straight from this browser to the API — there is no server in between, and nothing is sent anywhere else.

A browser can only call an API that allows this origin. If the call fails with a network error, that is CORS, not your key — point the base URL at a proxy you control.
